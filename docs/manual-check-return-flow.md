# Manual Check — Return Flow

Правило: ручная CAPTCHA/anti-bot проверка никогда не должна превращаться в тупик.
Любой переход в отдельный интерфейс проверки обязан иметь явный и безопасный возврат в исходный сканер.

## Контекст перехода

Перед открытием ручной проверки сохранять:

- session_id — текущая сессия сканирования;
- source_id — конкретный источник;
- source_url — URL источника;
- return_view — экран, откуда пользователь пришёл;
- return_state — состояние очереди/фильтров/позиции;
- return_action — что делать после возврата.

Хранение: локально в браузере/приложении. Не помещать секреты, cookies, токены или приватные данные в URL.

## Базовый поток

SCANNER
→ обнаружена проверка
→ источник ставится на PAUSED_MANUAL
→ пользователь нажимает «Пройти проверку»
→ открывается MANUAL CHECK
→ пользователь при необходимости открывает целевой сайт в отдельной вкладке
→ после проходки возвращается в MANUAL CHECK
→ выбирает результат
→ автоматический возврат в SCANNER
→ сканер восстанавливает прежний экран и очередь
→ действие применяется только к конкретному source_id

## Результаты ручной проверки

1. PASS
   - статус: MANUAL_PASSED
   - возврат в сканер
   - повторно проверить только этот источник
   - остальные источники не перезапускать

2. FAIL
   - статус: MANUAL_FAILED
   - возврат в сканер
   - источник оставить остановленным
   - показать краткую причину

3. SKIP
   - статус: SKIPPED_MANUAL
   - возврат в сканер
   - продолжить очередь со следующего источника

4. BACK / CANCEL
   - статус остаётся PAUSED_MANUAL
   - возврат в сканер
   - ничего не считать успешно пройденным

5. Вкладка/окно закрыты без выбора
   - статус остаётся PAUSED_MANUAL
   - при следующем открытии сканера показать незавершённую ручную проверку
   - не запускать этот источник автоматически

## Кнопки на MANUAL CHECK

- «Открыть сайт»
- «Проверку прошёл»
- «Не получилось»
- «Пропустить»
- «← Назад в сканер»

## Кнопка Back устройства / браузера

Back не должен терять состояние.

Если пользователь нажал системную/браузерную кнопку Back:
- вернуть в SCANNER;
- сохранить источник как PAUSED_MANUAL;
- восстановить исходную позицию и очередь;
- не запускать повторный запрос автоматически.

## Главное правило

Возврат всегда должен быть детерминированным:
MANUAL CHECK знает session_id + source_id + return_view.

После возврата восстанавливается именно тот сканер и именно тот источник, из которого пользователь пришёл.

Никакой ручной экран не должен:
- сбрасывать очередь;
- запускать весь скан заново;
- терять позицию;
- помечать CAPTCHA пройденной только потому, что пользователь вернулся назад.
